## Guidelines for Claude Sessions

Before beginning work in a Claude session, read the skill instructions under `.claude/skills/` (including each `SKILL.md`) and follow the applicable skills.

All comments in the code must be written in English.

`cbuild_parser` is generated by ANTLR. Do not edit it manually; make parser changes in the ANTLR grammar and regenerate `cbuild_parser` with ANTLR.
